# Cold Signal

For game design, prototype planning, game feel, art direction, playtesting,
release preparation, or balance work, use the matching Pocket Studio skill under
`.agents/skills/`.
Read its `SKILL.md` and the references needed for the current request.
If those links are unavailable, run `npm run skills:setup`.

When testing or improving a skill, follow [docs/pocket-studio.md](docs/pocket-studio.md).
Edit the canonical source in `tools/pocket-studio/skills/`; the installed folders
link there. Record findings under `docs/skill-trials/`, including both the game and
skill revisions. Commit reusable skill improvements in the Pocket Studio submodule;
commit game changes, trial evidence and the chosen submodule pin in Cold Signal.

For gameplay changes, read [the design](docs/design.md) and
[the verification record](docs/verification.md), then inspect the affected source.
Keep observed play, constructed scenarios and hypotheses distinct in findings.
